# Mova — Money Moves Better Together 🚀

A connected payment and collective finance platform built on top of MTN MoMo that replaces WhatsApp chaos, spreadsheets, and screenshots with direct social payment rails.

## Features
- **App Shell & Digital Identity**: Native mobile feel with desktop multi-column dashboard, verified MoMo identity pills (`@gabriel`), and 1-click personal/merchant switcher.
- **Group Split Engine (`/split`)**: Split bills equally or with custom weights, auto-USSD push reminders to pending members, and 1-tap WhatsApp group invites (`mova.me/s/weekend-trip-ada`).
- **Crowdfunding & Community Goals (`/fund`)**: Transparent, fraud-resistant mobile money crowdfunding without foreign bank accounts or overseas delays.
- **Micro-Merchant Portal (`/merchant`)**: Batch lunch orders (`@amakitchen`), real-time order matrices, verified printable digital receipts, and countertop QR standee generator.
- **Simulated MoMo API Rails (`/api/momo`)**: Full interactive USSD prompt simulator (`MoMoCheckoutModal`) with PIN approval testing and 1-tap WhatsApp receipt sharing.

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS with custom MoMo Yellow (`#FFD200`) and Deep Obsidian (`#0B0E14`) tokens
- **Typography**: Inter & Plus Jakarta Sans
- **Icons**: Lucide React
- **Animations**: Framer Motion
